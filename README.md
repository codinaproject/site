Site oficial da Codina — primeira versão
Este projeto é uma página inicial responsiva inspirada na composição visual de sites oficiais japoneses de anime, com identidade própria para a personagem Codina.
Arquivos
index.html — estrutura da página.
style.css — visual, layout responsivo e efeitos.
script.js — alternância de idioma e menu mobile.
Como testar
Abra index.html em um navegador. Para que o feed incorporado do X funcione, o navegador precisa ter acesso à internet e permitir os scripts externos do X.
Como publicar no GitHub Pages
Crie ou abra um repositório no GitHub.
Envie os três arquivos (index.html, style.css, script.js) para a raiz do repositório.
Entre em Settings → Pages.
Em Build and deployment, escolha a branch principal e a pasta / (root).
Salve e aguarde a publicação.
Personalizações futuras
Substituir os espaços reservados pela arte oficial da Codina.
Adicionar capítulos e informações de personagens confirmadas.
Revisar a tradução japonesa com base nos textos finais da obra.
Testar o feed do X no endereço publicado; a exibição depende do serviço de incorporação do X e pode variar.
Observação
A página não copia o site de Re:Zero; usa apenas referências gerais de composição e atmosfera visual. O conteúdo, a identidade e o layout foram criados para o projeto da Codina.
